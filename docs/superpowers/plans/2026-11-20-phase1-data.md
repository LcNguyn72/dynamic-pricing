# Phase 1 Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify UCI/M5 weekly panels and exact held-out test keys under protocol V2, without training models.

**Architecture:** Keep the historical demo and pilot artifacts intact. Give the shared retail preprocessor an explicit train-only outlier mode for the UCI V2 run. Generate UCI and all ten M5 store panels in new V2 directories, with source and panel hashes. Then materialize canonical test-key files and the M5 pricing cohort using train data only.

**Tech Stack:** Python, pandas, NumPy, standard-library unittest/CSV/hashlib/JSON.

**Spec:** `experiments/PROTOCOL_V2.md`, `experiments/protocol_v2.json`, `docs/dynamic-pricing-final-design.md`.

## Global Constraints

- Do only Phase 1; no model training, tuning, pricing policy rollout, API or frontend edits.
- UCI ID 352 and M5 evaluation are separate; preserve Online Retail II demo behavior and pilot files.
- Train fits outlier limits, SKU selector and scalers; held-out UCI valid sales are never removed by train IQR.
- Canonical test keys are observed forecast windows with 12 prior weeks, sorted by dataset, SKU, ISO Monday week, written UTF-8 CSV with `\n` endings and header `dataset,sku,week`.
- M5 pricing cohort uses one train-volume-leading eligible series per store, tie by SKU, then verifies the first 20 test weeks without test-based reselection.
- Work in the existing checkout because the research package is currently untracked and required by the user; do not commit or clean unrelated work.

## Review Focus

- A held-out UCI spike must remain in quantity and revenue, while the same outlier in train is removed.
- Selected UCI SKUs may lack first/last observations; the global source week calendar must still define 37/8/9.
- M5 zero-sales weeks with seven prices are test targets; incomplete-price weeks are not.
- The pricing cohort must not change when test quantities change; missing test weeks must fail rather than choose a replacement.
- The price-drop proxy must not silently become Song's observed promotion flag.
